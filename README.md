## Featured Projects

### [HomeSweet](https://github.com/ThyrexGG/Internship-Project) - [Live](https://internship-project-two-blush.vercel.app)
Rental and real-estate platform for Phnom Penh. Property search with map, rental applications, digital leases, ABA KHQR payments, real-time chat, roommate matching, 360-degree virtual tours and camera-based identity verification.
`Vue` `Firebase` `Vercel`

### [songKHEM](https://github.com/ThyrexGG/OCR-for-impaired-user) - [Live](https://ocr-for-impaired-user.vercel.app)
Accessibility app for blind and low-vision users. It scans Khmer documents (camera, image or PDF), reads them aloud with Azure neural voices, and highlights each word as it is spoken. Web app plus an Expo mobile app.
`Vue 3` `Expo` `Tesseract.js` `Google Cloud Vision` `Azure TTS`

### [Restaurant POS](https://github.com/ThyrexGG/Restaurant) - [Live](https://restaurant-three-chi-91.vercel.app)
Restaurant ordering and point-of-sale platform. Customers order by scanning a table QR code, staff manage live orders and inventory from an admin dashboard, and a Flutter POS app syncs with Loyverse in real time.
`React` `TypeScript` `Express` `Socket.IO` `Prisma` `PostgreSQL` `Flutter`

### [TradeLogger](https://github.com/ThyrexGG/Trade_Logger)
Trading journal and analytics platform. It syncs trades from MetaTrader 5 and Capital.com, then adds performance analytics, risk sizing, alerts, a backtesting lab and a read-only Gemini assistant. It never places orders. Clients: web, Electron desktop, Expo mobile.
`Python` `FastAPI` `PostgreSQL` `React` `Vite` `Tailwind` `Electron`

### Buried Kingdom (Roblox, private)
A large treasure-digging adventure game written in Luau. It has digging with obstacles, relics with powers, pets, boss fights, a rising dungeon tower, far regions, and original music. It has automated tests (Lune and Selene) and is committed in small, tested steps.
`Luau` `Roblox Studio`

### [CAM Clothing Shop System](https://github.com/ThyrexGG/Java)
Java console app modelling a shop's order workflow, built to practise OOP: abstraction, inheritance, polymorphism, interfaces and encapsulation.
`Java`

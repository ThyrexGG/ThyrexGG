## About Me

I'm a Year II Bachelor of Software Engineering student at CamTech in Phnom Penh. I like shipping whole products: the database, the API, and the web, mobile and desktop clients that sit on top.

<table>
  <tr>
    <td width="33%" valign="top">
      <h4>What I build</h4>
      Complete products, from database and API to web, mobile and desktop clients. Offline-first apps, real-time ordering, digital leases, KHQR payments, OCR with text-to-speech, and trading analytics.
    </td>
    <td width="33%" valign="top">
      <h4>How I work</h4>
      Small steps, version control, and docs that let anyone pick the project back up. I lead a five-member team on HomeSweet, and I use AI tools such as Claude Code as a pair programmer while keeping every change reviewed and tested.
    </td>
    <td width="33%" valign="top">
      <h4>What is next</h4>
      Cloud computing, system design and deeper backend engineering. Every project I start is meant to be a bit harder than the last one.
    </td>
  </tr>
</table>
